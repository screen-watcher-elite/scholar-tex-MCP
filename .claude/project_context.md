# ScholarTex MCP — Claude Code Project Memory

## Core Details
- **Project**: ScholarTex MCP (Academic Mathematical Proof & LaTeX Scribe)
- **Author / Maintainer**: `screen-watcher-elite`
- **Target Repository**: `https://github.com/screen-watcher-elite/scholar-tex-MCP`
- **Primary Use Cases**: Engineering mathematical derivations, tensor shape validation, publication TikZ generation, Overleaf LaTeX reports.

## Tools Summary
1. `derive_step_by_step`: Step-by-step proofs for Backpropagation, Softmax Cross-Entropy, SVD, Ridge Regression, PCA, and Gram-Schmidt.
2. `verify_matrix_dimensions`: Tensor dimension checking ($Wx + b$, outer products, Jacobians, broadcasting).
3. `generate_tikz_diagram`: Compilable TikZ figures for MLPs, Transformers, DAGs, and 2D/3D coordinate transformations.
4. `format_latex_document`: Overleaf-ready LaTeX templates (Article, IEEE, Beamer, Cheat Sheet).
5. `render_math_chalkboard`: Unicode blackboard box summaries for terminal and notes.
